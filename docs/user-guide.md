# User guide

Add confirmed folders through the native picker. Category routes are created
when files are organized. Organize Now processes configured folders; Automatic
keeps watching while the application is running. Existing subfolders stay put.

Use Rules to enable, edit or remove extension/contains conditions. History keeps
the latest 200 events; search filenames and filter by source folder, date/status.
Select a row for native expandable details. Select/copy the raw path fields with
Ctrl+C, or use Open Folder for successful destinations. Enter opens the selected
destination folder; Space toggles selected details when the list has focus.

Language/theme controls update in place. Optional tray mode hides the window on
Close; Show restores it and monitoring continues. Tray Quit actually exits after
safe cleanup. Without tray mode, Close initiates shutdown. The app has no undo,
backup, permanent-delete command, startup registration or automatic updater.
