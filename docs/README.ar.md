# FileFlow

**ملفاتك مرتبة تلقائياً.**

تطبيق محلي لويندوز لتنظيم الملفات حسب النوع أو قواعد الامتداد واحتواء الاسم.
يدعم العربية والإنجليزية والوضعين الفاتح والداكن والمراقبة في علبة النظام.

نزّل ملف ZIP الكامل من صفحة إصدارات المشروع على GitHub وفك ضغطه،
ثم شغّل FileFlow.exe مع إبقاء مجلد _internal بجانبه. لا تحتاج إلى تثبيت Python.
البرنامج غير موقّع رقمياً. اختُبر على Windows 11؛ اختبار Windows 10 لم يكتمل.

أضف مجلداً وأكّد الإعداد، ثم خصص الوجهات أو القواعد وفعّل التنظيم التلقائي.
لا يعيد التطبيق ترتيب المجلدات المتداخلة، ولا يوفر تراجعاً تلقائياً أو نسخاً
احتياطياً. إغلاق النافذة مع تفعيل علبة النظام يبقي المراقبة نشطة؛ الخروج
من قائمة العلبة ينهي التطبيق بأمان. لا تشارك سجلك أو مساراتك الخاصة علناً.
