# Security

Only the current 1.2.2 line is intended to receive fixes; this is not an SLA or a
promise of support for every Windows release.

GitHub private vulnerability reporting is enabled and was verified at launch.
Use the [repository Security page](https://github.com/Mohammed-Alharbi-1/FileFlow/security)
to report a vulnerability privately (GitHub sign-in may be required).
Do not post exploit details, credentials, user settings or private file lists in
public issues. Treat file-loss/collision bypass reports as high priority.

Include Windows/application versions and a minimal example using synthetic files.
Never test a suspected file-loss issue on your actual personal folders.
