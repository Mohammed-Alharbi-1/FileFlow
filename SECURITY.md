# Security

Only the current 1.2.2 line is intended to receive fixes; this is not an SLA or
promise of support for every Windows release. No public repository contact or
private vulnerability reporting channel is configured yet.

Use the repository Security page's private reporting control if enabled.
Until a verified private channel is available, do not post
exploit details, credentials, user settings or private file lists in public issues.
This document deliberately does not invent an email/contact or claim reporting
is already enabled. Treat file-loss/collision bypass reports as high priority.
