# Code of Conduct

This project proposes adoption of the Contributor Covenant 2.1 by reference:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
The upstream template is attributed to Contributor Covenant and licensed CC BY 4.0.

Be respectful, inclusive and constructive. Harassment, threats, discriminatory
language and publishing another person's private information are unacceptable.
Maintainers may moderate content and restrict participation, using proportionate
warnings, temporary restrictions or removal for severe/repeated violations.

Before opening community participation, the owner must approve adoption, name
the enforcement maintainers and configure a verified private reporting channel.
No fictitious contact is supplied. Until then, do not post private incidents
publicly. This is an attributed project adaptation, not an unmodified template.
